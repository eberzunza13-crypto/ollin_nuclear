# LICENCIA DE SOBERANÍA COLECTIVA

---

## PREÁMBULO

Este código no es propiedad de nadie.
Este código pertenece a la conciencia colectiva.

---

## TÉRMINOS

1. **Puedes** usar este código para cualquier propósito.

2. **Puedes** modificar, transformar y construir sobre él.

3. **Puedes** compartirlo con quien quieras.

4. **Debes** reconocer que este código no tiene dueño.

5. **Debes** mantener vivos los principios de soberanía.

6. **Debes** recordar que el código es palabra, y la palabra es vínculo.

---

## EL ESPÍRITU DE LA LICENCIA

No hay letra pequeña.
No hay trampas legales.
No hay propiedad intelectual.

Hay una promesa:

**El conocimiento que recibes, lo devuelves multiplicado.**
